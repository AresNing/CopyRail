## Settings typography and native glass (2026-09-10)

Local **beta.19** unifies settings around the system font: 16-point page titles, 13-point labels/controls and 12-point supporting text. General adds **Background transparency**, default 50%, from an opaque surface (0%) to native macOS frosted glass (100%). It saves independently of other drafts and propagates across rail/settings/preview. Foreground text and controls remain fully opaque. Reduced transparency, increased contrast and forced colors use opaque backgrounds. Legacy preference JSON preserves existing values and supplies the new default; invalid values are rejected.

The native material is an active HUD `NSVisualEffectView`, installed once per persistent panel. Slider changes only adjust background tints, never panel alpha, geometry or lifetime. Native inspection caught an older settings background overriding the new tint; that cascade conflict was corrected and the regression check now measures the actual panel background alpha as well as the setting.

Validation: **365 Rust tests passed, 4 ignored**, formatting, strict host/WASM Clippy and frontend build passed. **Seven compiled-UI groups** passed on the final assets: appearance, workspace interactions, detached workspace, language, toolbar/settings, visual and design. English synthetic README captures were regenerated; all eight reports match the delivered assets. Browser IPC remains synthetic and cannot prove native blur.

This is a visual/geometry check, not a repeat of beta.17's frame-by-frame flicker recording. No real paste, user-history capture, login preference, Accessibility or system security change was made.
