A few things to know.

Which Macs are supported?

The 1.0 download is for Apple Silicon Macs (M1 or later) running macOS 13 or later. Intel, Windows and Linux installers are not included.

What should I expect on first launch?

CopyRail is locally signed, without Apple Developer ID signing or notarization. macOS may ask you to allow it in Privacy & Security. Follow the installation guide. Direct paste also needs Accessibility permission; copying an item does not.

Does my clipboard sync to the cloud?

No. Version 1.0 stores history locally and does not include multi-device sync. History and exported backups are not encrypted by the app. You can pause capture or exclude apps in Settings.

Is CopyRail free and open source?

Yes. Project-owned code and graphics are licensed under Apache-2.0. You can read the source, build it yourself and contribute. Third-party components keep their own licenses.

Where can I report an issue?

Use GitHub Issues for feedback and bug reports. Cross-app behavior and compatibility are still being expanded; the verification record lists what has been tested and what remains open.
